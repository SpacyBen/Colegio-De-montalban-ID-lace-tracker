# 🏫Colegio-De-montalban-ID-lace-tracker🏫
This project uses YOLOv11 and computer vision to automatically detect whether 
students are wearing their ID laces at Colegio de Montalban. It helps improve compliance and security monitoring.

Future improvements:
- Extend detection to different angles and occlusions.
- Add real-time alerts or notifications when ID laces are missing.
- Integrate with school attendance or access control systems.
- Improve accuracy with more diverse training data.
- Add Exact ID card verification
